# Haiss_et_al_2026
This repository contains scripts and analyses supporting the manuscript "Tandem repeats in methanogenic archaea and their viruses reveal a shared potential for rapid genomic diversification".

The data includes:
- Python-based tandem repeat finder with mismatch tolerance (modified from https://github.com/rohansachdeva/tandem_repeats)
- Python-based script to calculate pairwise TR-similarity between genomes
- Python-based script to test for enrichment/depletion of TRs in genomic neighborhood
- Python-based script to test for enrichment/depletion of aaTRs in proteins
- Python-based script to test the enrichment of TRs next to specific genes
